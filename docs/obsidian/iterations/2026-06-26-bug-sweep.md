## Bugs corrigés

1. **`GameApp.resize()` — aspect NaN/Infinity** (`game/GameApp.ts`)
   - `camera.aspect = width / height` sans garde : si le conteneur est masqué ou
     pas encore mis en page (`clientHeight === 0`), `aspect` devient `Infinity`/`NaN`,
     ce qui corrompt la matrice de projection (rendu noir jusqu'au prochain resize).
   - Fix : early-return si `width <= 0 || height <= 0`.

2. **`fournaise.ts` — `lavaFx` non réinitialisé** (`render/fournaise.ts`)
   - `waterFx` (écume) est reset à chaque build, mais `lavaFx` (lueur lave) ne l'était pas.
     Si le blockout Fournaise est rebâti, `updateFournaiseFx` animerait des meshes
     orphelins (fuite + refs périmées).
   - Fix : `lavaFx.length = 0` en tête du build, cohérent avec `waterFx`.
