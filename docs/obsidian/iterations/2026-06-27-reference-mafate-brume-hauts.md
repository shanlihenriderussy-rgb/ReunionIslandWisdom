# 2026-06-27 - Reference Mafate / brume des hauts

## Source

![[../assets/references/mafate/2026-06-27-mafate-brume-hauts.jpg]]

## Lecture

- Ciel lourd, nuages bas, lumiere froide.
- Relief lisible par plans successifs voiles par la brume.
- Vegetation de hauts en masses sombres : tamarins / cryptomerias stylises.
- Sol moins tropical : herbes seches, brun-gris, rochers sombres, friches ouvertes.
- Ambiance plus isolee et venteuse que le littoral Saint-Paul / Saint-Gilles.

## Traduction jeu

- Utiliser cette reference pour le belvedere Maido / Mafate.
- Garder le style low-poly lisible : formes simples, aplats, silhouettes fortes.
- Ajouter brume/fog locale sur les plans lointains avant d'ajouter trop de props.
- Vegetation cible : coniferes/cryptomerias, buissons sombres, fleurs jaunes ponctuelles.
- Ne pas utiliser la photo comme texture ou asset final.

## Risque a eviter

- Ne pas assombrir tout le jeu : cette ambiance est reservee aux hauts.
- Ne pas remplacer le moodboard B3 : cette photo le complete avec une direction plus locale.
